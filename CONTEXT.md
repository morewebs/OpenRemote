# OpenRemote

OpenRemote runs chats through Apps on a person's own computers.

## Language

**Machine**
A computer that runs Apps and their chats. A Cloud machine can run chats for the person's other devices.

**App**
A chat runtime such as Codex or Claude Code that can be installed on a machine.
_Avoid in the interface_: Harness

**App account**
A sign-in to an App's provider on a machine. One App installation can have more than one App account.
_Avoid_: OpenRemote account
