# OpenRemote 0.6.0

## Phone

- Settings, and the other views that open over the app, now sit above the sidebar. Opening one closes the drawer, and the page can no longer be dragged aside while a view is open.
- Back returns to the screen you came from. A second press no longer skips past a view that was still opening.

## Downloads

- **ARM64:** [OpenRemote-arm64.apk](https://github.com/morewebs/OpenRemote/releases/download/v0.6.0/OpenRemote-arm64.apk) for phones running 64-bit ARM Android.
- **ARMv7:** [OpenRemote-armv7.apk](https://github.com/morewebs/OpenRemote/releases/download/v0.6.0/OpenRemote-armv7.apk) for phones running 32-bit ARM Android.
- The universal APK is also available. Choose the matching ARM APK for a smaller download.

Install the matching APK over the existing app to keep its data. Android 8 or newer is required.

Desktop installers are unsigned. Windows SmartScreen may warn: More info > Run anyway.
