# OpenRemote 0.5.1

## Fixed

- Android Cloud sign-in no longer fails with "can't save this device's Cloud files: Permission denied (os error 13)" after authorization. Saving a new device identity now uses an atomic operation Android permits, while preserving its protection against overwriting an existing identity.

## Downloads

- **ARM64:** [OpenRemote-arm64.apk](https://github.com/morewebs/OpenRemote/releases/download/v0.5.1/OpenRemote-arm64.apk) for phones running 64-bit ARM Android.
- **ARMv7:** [OpenRemote-armv7.apk](https://github.com/morewebs/OpenRemote/releases/download/v0.5.1/OpenRemote-armv7.apk) for phones running 32-bit ARM Android.
- The universal APK remains available when the device architecture is unknown. The standalone APKs contain one native architecture each, making them smaller downloads.

Install the matching APK over the existing app to keep its data. Android 8 or newer is required.

Desktop installers are unsigned. Windows SmartScreen may warn: More info > Run anyway.
