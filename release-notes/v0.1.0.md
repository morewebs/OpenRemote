First release.

OpenRemote is a local console for the coding-agent harnesses on your
machine - Claude Code, Codex, grok, pi, opencode, and agy - run side by
side in one desktop window (Tauri 2 + React 19). A Rust daemon wraps the
harness CLIs and serves the console over localhost; the desktop app
ships it as a sidecar, so nothing leaves the machine. Cloud mode is
marked coming soon.

## Install (Windows 10+)

Download `OpenRemote_0.1.0_x64_en-US.msi` or the NSIS setup exe and run
it.

The installers are unsigned: SmartScreen will show "Windows protected
your PC". Choose More info > Run anyway.

## Build from source

npm ci, stage the daemon sidecar (`OR_RELEASE=1 npm run daemon`), then
`npx tauri build`. See the README.
