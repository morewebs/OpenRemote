First release.

OpenRemote is one desktop window for the coding-agent harnesses on your
machine - Claude Code, Codex, Grok Build, Pi Agent, OpenCode and
Antigravity - run side by side. A Rust daemon wraps the harness CLIs and
serves the console over localhost; the desktop app ships the daemon
inside, so nothing leaves the machine. No telemetry.

Cloud mode joins your own computers - a laptop, a home server, a VPS -
through a moreweb account: chats run on whichever machine you pick and
are copied to all of them, end to end encrypted. The relay only ever
forwards ciphertext and stores no chats - not even we can read them.
Cloud is new: this is its first public outing, and we are testing it in
the open.

The Android app is a phone in that Cloud. A phone runs no harnesses, so
it never runs a chat itself - it reads, steers and starts chats that
run on your machines, and answers approvals from anywhere. It needs a
moreweb account with at least one machine connected.

## Install

**Windows** - run the MSI or the setup exe. The installers are
unsigned: SmartScreen will show "Windows protected your PC" - choose
More info > Run anyway.

**Linux** - the AppImage needs `chmod +x` and then runs anywhere; the
deb installs with your package manager.

**Android** - allow installing unknown apps for your browser or file
manager, then open the APK. It is signed with a development key, not
verified by Play Protect.

## Build from source

Desktop: `npm ci`, stage the daemon sidecar (`OR_RELEASE=1 npm run
daemon`), then `npx tauri build`. Android: `source
scripts/android-env.sh`, then `npx tauri android build`. See the
README.
