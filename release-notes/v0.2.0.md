Projects, and automations on a firm footing.

OpenRemote is one desktop window for the coding-agent harnesses on your
machine - Claude Code, Codex, Grok Build, Pi Agent, OpenCode and
Antigravity - run side by side. A Rust daemon wraps the harness CLIs and
serves the console over localhost; the desktop app ships the daemon
inside, so nothing leaves the machine. No telemetry.

## Projects

A project is a folder you register - once, from one place: the `+` beside
Projects in the sidebar, or the Add project button on the home screen.
Both open the same in-app folder picker, so adding a project on another
of your machines (Cloud) works exactly like adding one here: you browse
that machine's disk and pick the folder.

The sidebar now holds two sections. **Projects** - each registered
project with its chats under it, a caret, and a count. **Chats** - every
chat that belongs to no project, in one flat list. Removing a project
never deletes anything: the folder stays on disk and its chats drop to
the flat list.

A new chat picks a project - or none at all. A project-less chat runs in
your home folder and shows up under Chats. There is no folder browsing
in the app outside the picker: the OS dialog is retired, local and
remote pick the same way.

Automations speak projects too: a rule's chat runs in one of your
registered projects, picked from the same list.

## Automations

Schedule and webhook rules work end to end - create, edit, enable, run
now, delete, with each rule's chat one click away and its webhook key in
its URL. A rule that can't fire says why: a machine that hasn't checked
in, a project folder that went missing, each surfaced in the list.

|---|---|

## Install

- **Windows:** run the installer. The daemon starts with the app; the
  token handshake is automatic.
- **Linux:** `chmod +x` the AppImage and run it, or install the `.deb`.
