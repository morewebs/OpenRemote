# OpenRemote 0.6.7

## Windows

- In-app updates are switched on. The app carries the updater's public key, so it reads the signed update feed and can say whether a newer release is there.
- The About modal's badge now reports a real state: Up to date when the app is current, Update available when a newer signed release is waiting, and Retry when the check fails.
- An update downloads in the background as soon as a check finds it, is verified against the key the app was built with, and installs when the user confirms. The daemon is stopped first, and the confirmation names the chats that will stop when the app restarts.
- Smaller updates ship beside the full one: a patch from the installed version's own installer when the app kept it, else the packed installer, else the release's own installer. Each is checked against the same signature.
- Copies installed before this release carry no updater key, so they keep reporting that updates are unavailable. Install this release once by hand and every later update arrives on its own.

## Nightly

- The nightly has its own key and its own feed, so a nightly install is offered nightly builds and a stable install is offered stable ones.
