# OpenRemote 0.6.6

## Windows

- Add an update status badge at the far right of the version row in About, matching the Android badge.
- Opening About checks the existing signed update feed. The badge shows checking, up to date, an available update, or Retry if the check fails.
- Clicking an available update opens the existing install-and-restart confirmation, including the warning for chats running on this computer. Download preparation, signature verification, and installation use the existing Windows updater.
- Builds without an updater signing key report Updates unavailable instead of incorrectly reporting that the app is current.

Install the matching APK over the existing app to keep its data. Android 8 or newer is required.

Desktop installers are unsigned. Windows SmartScreen may warn: More info > Run anyway.
