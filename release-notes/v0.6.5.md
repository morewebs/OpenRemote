# OpenRemote 0.6.5

## Phone

- Organize expanded chat options into labelled columns, with permissions on the right. Saved setups remain accessible as more options are added.
- Add a plus attachment button on the left of the composer for apps that support pictures.
- Keep project and model pickers within the screen, including while the keyboard is open. Menus inside dialogs remain accessible to keyboard focus.
- Improve chat context menus with larger touch targets, scrolling for long menus, and tap-outside dismissal.
- Keep delete-chat and folder dialogs above the sidebar. Folder browsing now shows loading, errors, and Retry instead of a blank list.
- Show an update status badge at the right of the version in About for Android GitHub builds: checking, up to date, or an available APK download. Future Google Play builds omit this checker.

## Downloads

- **ARM64:** [OpenRemote-arm64.apk](https://github.com/morewebs/OpenRemote/releases/download/v0.6.5/OpenRemote-arm64.apk) for phones running 64-bit ARM Android.
- **ARMv7:** [OpenRemote-armv7.apk](https://github.com/morewebs/OpenRemote/releases/download/v0.6.5/OpenRemote-armv7.apk) for phones running 32-bit ARM Android.
- The universal APK is also available. Choose the matching ARM APK for a smaller download.

Install the matching APK over the existing app to keep its data. Android 8 or newer is required. About opens the official APK download; Android asks you to confirm installation.

Desktop installers are unsigned. Windows SmartScreen may warn: More info > Run anyway.
