# OpenRemote 0.5.2

## Mobile homescreen

- A quieter welcome and a compact composer at the bottom of the screen replace the desktop-style centered task box.
- The smaller header includes Browser access. Machine and project selectors sit above the composer; Chat options holds model, effort, permissions and saved setups.
- Larger touch targets and menus that stay inside the available screen make the setup controls easier to use on a phone.
- Offline computers, pending inventories, missing Apps and installed but disabled Apps each show the appropriate next step.
- Reopening New chat correctly selects an existing computer instead of asking you to connect one again.

## Downloads

- **ARM64:** [OpenRemote-arm64.apk](https://github.com/morewebs/OpenRemote/releases/download/v0.5.2/OpenRemote-arm64.apk) for phones running 64-bit ARM Android.
- **ARMv7:** [OpenRemote-armv7.apk](https://github.com/morewebs/OpenRemote/releases/download/v0.5.2/OpenRemote-armv7.apk) for phones running 32-bit ARM Android.
- The universal APK is also available. Choose the matching ARM APK for a smaller download.

Install the matching APK over the existing app to keep its data. Android 8 or newer is required.

Desktop installers are unsigned. Windows SmartScreen may warn: More info > Run anyway.
