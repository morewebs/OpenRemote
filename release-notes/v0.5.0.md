Plugins, pictures, a fuller browser, and agents that work as a team.

This release gathers the work that lived on side branches since 0.4.8 and
brings it onto one line. It is a big one, so the list below is grouped by
where you will meet it.

## New

- **Pictures in chats.** Paste, drop or pick a picture in the composer and it
  reaches Claude and Codex. An App that cannot read pictures says so before
  anything is sent, instead of dropping them.
- **Agent teams.** A chat's agent can start other chats as workers and hear
  back from them. Workers nest under their lead in the sidebar, the lead's chat
  shows its team, and Settings > Agents puts the limits in plain words.
- **Plugins.** A plugin can add tools for agents (as a small WebAssembly module
  or a program it ships), its own page in the sidebar, buttons in the composer,
  and settings. You choose who a plugin is for: this computer, one project, or
  every device on your account. Nothing a plugin may do comes from the plugin
  itself: you approve its powers when you install it, on each device. Plugins
  written in Claude Code's layout install too, and the review lists what was
  adapted. Dictation, a toy harness and an SSH plugin ship as examples.
- **Browser.** Tool output in the chat; a permission bar; private tabs that
  remember nothing; full screen; tabs that come back after a restart and are
  put away past ten; an "agent is browsing" badge with Take over; new-tab
  shortcuts; address-bar completion; a bookmarks manager; screenshots and
  recordings straight into the composer.
- **Import from another browser.** Settings > Browser brings bookmarks and
  history in from Chrome-family browsers, Firefox and Safari. It only reads
  their files, never cookies, passwords or site data, and one import adds at
  most 2,000 bookmarks so it cannot flood your other devices.
- **Ad blocking.** Off until you turn it on in Settings > Browser, and no filter
  list is downloaded until you pick one. Each list names its licence.
- **Move a chat to another project.** Right-click, or drag it onto a project.
  Claude conversations come along, Codex resumes in the new folder, and other
  Apps get the chat so far as context.
- **Android browser.** On the phone each tab is a real Android web view, with a
  phone layout, private tabs that block screenshots, and pages that sleep only
  when memory is short.
- **Sidebar.** A folded project shows how many of its chats are running or
  failed, double-click renames, and an empty rename brings back the first
  message's name.

## Changed

- **Agents are sent less.** OpenRemote's tools and the open-tabs note used to
  ride on every request. A plain Claude chat now carries about 700 tokens of
  them instead of about 3,700: the browser and team tools appear once a chat
  uses them, and the tabs note goes only to chats that browse, and only when
  the tabs change. Settings > Browser can give every chat the tabs and browser
  tools again.
- **OpenCode keeps your permission choice.** A chat's permission setting now
  reaches OpenCode; before, it ran on OpenCode's own default.
- **An update path, switched off.** The app can check once a day for a newer
  signed release and stop its daemon before installing it. It stays off until
  a signing key is set, so this release does not update itself yet.

## Known

- Installers are unsigned. Windows SmartScreen may warn: More info > Run anyway.
- The Android browser has not yet been checked on a phone, and the plugin
  pages, ad blocking and browser import have been checked by tests rather than
  by hand.
- Codex 0.167 no longer accepts "Ask when it fails"; pick another approval
  setting for Codex chats until that choice is fixed.
- An installed app still does not look for a newer version. Moving to a newer
  release means running a newer installer over it, or `openremote --update` if
  you installed through npm.
